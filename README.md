# Banknotenprüfung

## Projektbeschreibung

Dieses Projekt wurde im Rahmen des Unterrichts an der IT-Akademie Dr. Heuer erstellt.

Die Anwendung ermöglicht die Überprüfung von Banknoten-Seriennummern auf drei verschiedene Arten:

* Einzelprüfung einer Seriennummer
* Listenprüfung mehrerer Seriennummern
* Datei-Upload mit automatischer Prüfung der enthaltenen Seriennummern

Zusätzlich wurde die Anwendung erfolgreich in Microsoft Azure veröffentlicht.

## Verwendete Technologien

* ASP.NET Core MVC
* C#
* Razor Views
* Bootstrap
* Microsoft Azure App Service
* PowerShell
* Azure CLI

## Azure Deployment

Für die Bereitstellung wurde:

1. Eine Azure Resource Group erstellt
2. Ein App Service Plan erstellt
3. Eine Azure Web App erstellt
4. Das Projekt aus Visual Studio veröffentlicht

Zusätzlich wurde ein PowerShell-Skript zur Erstellung der Azure-Ressourcen verwendet.

## Hinweis

Die Klasse **„Seriennummerprüfer“** wurde im Rahmen der Unterrichtsaufgabe vom Dozenten bereitgestellt.

Die Integration der Klasse in die MVC-Anwendung, die Benutzeroberfläche, die Controller-Logik, die Datei-Verarbeitung sowie die Veröffentlichung in Microsoft Azure wurden im Rahmen dieser Projektarbeit umgesetzt.
